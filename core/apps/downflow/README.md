# ⚡ Flowork DownFlow — Sovereign First-Party Download Engine

Flowork DownFlow is a high-speed, parallel segmented download accelerator natively built in pure Rust for Flowork OS.

## Features
- **Pure Native Rust**: Zero Python runtime, zero Electron bloat, static ELF binary execution.
- **Multi-Part Acceleration**: Automatic parallel chunk downloading via HTTP/HTTPS range streaming.
- **Browser Native Messaging**: Full bidirectional integration with Chromium and Chrome via Native Messaging protocol.
- **Model Context Protocol (MCP)**: Native stdio JSON-RPC server enabling AI agent orchestration by Mr. Flow.
- **TUI Dashboard & CLI**: Rich terminal monitoring with Ratatui and headless scripting via `downflow-cli`.
- **Apache-2.0 License**: 100% clean-room sovereign code.
