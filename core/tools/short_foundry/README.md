# Flowork Short Foundry Tool (`flowork-short`)

Autonomous vertical 9:16 short video generator for social media (Shorts, Reels, TikTok).

## Usage
```bash
# Standard 56s short generation
flowork-short --topic "Disiplin Finansial"

# Custom duration and output
flowork-short --topic "Mental Juara" --duration 50 --output /opt/floworkos/documents/videos/mental_juara.mp4

# Run Rapid Self-Diagnostic QC Test
flowork-short --qc-test
```
