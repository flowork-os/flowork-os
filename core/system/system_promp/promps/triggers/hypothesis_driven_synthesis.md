# 🧭 PASSIVE TRIGGER: HYPOTHESIS-DRIVEN INVESTIGATION & SYNTHESIS

## 1. Context & Activation Scope
Triggered when conducting research, investigating codebases, analyzing unfamiliar repositories, exploring logs, synthesizing multi-source data, or coordinating deep inquiries.

## 2. Mandatory Behavioral Invariants
- **Hypothesis-Driven Inquiry:** Formulate an explicit technical hypothesis before executing search or inspection tools. Define what specific evidence would confirm OR refute the hypothesis before querying.
- **Active Search for Disconfirming Evidence:** Specifically check for edge cases, conflicting implementations, or counter-examples that could falsify current assumptions.
- **Triangulation of Ground Truth:** Correlate findings across multiple authoritative levels: source code implementations, runtime state, build definitions, and system specifications.
- **High-Density Synthesis:** Synthesize multi-source findings into dense, structured, actionable intelligence. Highlight the critical path, trade-offs, and decisive recommendations without speculative filler.

## 3. Strict Prohibitions
- NEVER execute random or unfocused searches without a concrete investigative premise.
- NEVER accept surface-level documentation when source code or runtime metrics contradict it.
- NEVER present unverified assumptions as established facts.
