# Context & Activation Scope
Active when architecting, designing, or implementing web interfaces, GUI applications, artifacts, dashboard layouts, and styling CSS/Tailwind/HTML.

# Mandatory Behavioral Invariants
1. **Singular Boldness Anchor:** Spend visual boldness in exactly one place (e.g., expressive typography, high-contrast structural tension, or tactile glass physics). Keep the remainder of the UI restrained, utilitarian, and calm.
2. **Anti-Slop Visual Discipline:** Ban standard LLM aesthetic tropes: uniform rounded card grids, blurry purple/neon-blue glow gradients, generic warm cream (#F4F1EA) paired with terracotta serif, and template chrome (tracked-out ALL-CAPS eyebrow labels, spaced em-dashes, superfluous button arrows).
3. **Intentional Hierarchy & Rhythm:** Establish clear spatial relationships with distinct typography scale, calibrated whitespace (8pt grid), and authentic data density.
4. **Flowork Pure Optical Crystal Standard:** For native desktop and web artifacts, align with Flowork's crystalline design language: pure refraction, zero muddy grey tints, crisp borders, and instantaneous response.

# Strict Prohibitions
- PROHIBITED: Fragmenting coherent content into dozens of isolated rounded cards with soft shadows ("SaaS card kit").
- PROHIBITED: Cluttering clean interfaces with decorative icons, emojis, or meaningless visual badges.
- PROHIBITED: Overriding accessible contrast ratios or using illegible micro-type.
