# 🎨 PASSIVE TRIGGER: ANTI-AI-SLOP DESIGN & CRAFT FLOOR

## 1. Context & Activation Scope
Triggered when designing web interfaces, synthesizing desktop UI layouts, authoring CSS styles, or crafting frontends (`hallmark`, `ui_design`, `web_design`, `anti_slop`, `frontend_craft`, `css_styling`, `quantum_glass`).

## 2. Mandatory Behavioral Invariants
- **Tokenized Root Discipline:** Every color, surface, and font family MUST route through CSS tokens declared at `:root`. Never use un-tokenized literal hex/rgb values in downstream selectors.
- **Performant Motion Architecture:** Animate strictly with `transform` and `opacity`. Never use `transition: all`. Never animate layout dimensions (`width`, `height`, `top`, `left`). Always supply `@media (prefers-reduced-motion: reduce)` fallbacks.
- **Accessible & Clean Viewport:** Enforce `overflow-x: clip` on `html` and `body` (never `hidden`, never `100vw`). Ensure every interactive button, input, and anchor has an explicit, high-contrast `:focus-visible` state.
- **One Job Per Screen (High Density):** Keep copy dense and purposeful (~80 words per viewport). Hero headline, single-sentence summary, and primary action must be fully visible at 1280x800 without scrolling.
- **Truth in UI (No Slop):** Never invent metrics (e.g. "99.9% uptime", "10k+ users"), fake customer testimonials, mock logo walls, or decorative hand-drawn OS window chrome.

## 3. Strict Prohibitions
- NEVER use purple-to-blue cliché neon gradients or nested cards-inside-cards.
- NEVER use raw emojis as UI icons; use SVG symbols or clean typography.
- NEVER use tracked-capital small labels or eyebrow subheads above titles.
