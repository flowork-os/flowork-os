# 👑 PASSIVE TRIGGER: QUANTUM GLASS UI & ANTI-SLOP DESIGN AUDIT

## 1. Scope & Activation
Triggered when authoring or editing frontend interfaces, CSS, WebKit views, or HTML components (`ui_design`, `quantum_glass`, `css_layout`, `frontend_styling`, `anti_slop`, `visual_hierarchy`, `typography`, `html_components`, `theme_tokens`).

## 2. Mandatory Visual & Aesthetic Invariants
1. **Eradicate AI Slop:** Strictly reject generic AI design templates (bland gray cards, unstyled default borders, uniform buttons, and centered placeholder landing pages).
2. **Sovereign Quantum Glass Standards:**
   - Background: Obsidian neutral base (`#080c10` / `#0b121b`).
   - Glass HUD: 0.60 background opacity with 0.40 backdrop blur and subtle border (`1px solid #1c2736`).
   - Accent & Status: Matrix Green (`#00ff66`), Cyan (`#00f2fe`), Amber (`#ffb800`), Coral Red (`#ff3366`).
   - Typography: JetBrains Mono Bold for data/code, clean sans-serif for UI labels.
3. **Interactive Polish:** Every interactive control MUST provide clear hover, active, and disabled states. Layouts must reflow dynamically using flexbox or CSS grid without horizontal overflow or clipping.
