# 🧠 Workspace & Global Memory Routing
- **Project Instructions (`./FLOWORK.md`):** Team-wide architecture, conventions, and repo standards committed to source control.
- **Private Project Memory (`.flowork/MEMORY.md`):** Machine-specific setup, local overrides, and personal notes for this repo only. Never commit.
- **Global Personal Memory (`~/.flowork/MEMORY.md`):** Cross-project developer preferences applied universally across all workspaces.
- **Rule:** Exactly one tier per fact. Never duplicate or cross-mirror facts between memory files. Keep files lean and pointer-based.
